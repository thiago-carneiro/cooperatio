# Engine

Nesta escala, a montagem é o writer escrevendo `guia-de-adocao.md` diretamente, e o orquestrador passando caminhos (nunca resumos) entre os papéis; não há motor separado. Se a célula crescer, o motor entra aqui: núcleo do grafo com hash por artefato, roteador de notas que recusa alvo desconhecido, montagem que valida contratos antes do trabalho caro e saída nomeada por rótulo de versão.
